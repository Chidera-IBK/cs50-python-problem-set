# cs50-python-problem-sets

A collection of all problem sets completed throughout Harvard’s CS50’s Introduction to Programming with Python (CS50P). Each folder contains the solutions for that week’s problem set.

-----

## Course Overview

CS50P is Harvard University’s introduction to programming using Python. The course covers everything from the basics of functions and variables all the way to object-oriented programming and advanced Python topics.

## What I Learned

- Writing clean functions and working with variables
- Making decisions in code using conditionals
- Repeating logic efficiently with loops
- Handling errors gracefully with exceptions
- Using Python’s powerful built-in libraries
- Writing unit tests to verify code correctness
- Reading and writing files with File I/O
- Pattern matching with regular expressions
- Building programs using Object-Oriented Programming
